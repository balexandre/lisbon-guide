# Lisbon, from someone who grew up there

A single-page guide to Lisbon and the coast around it

## GitHub Pages

Hosted in GitHub Pages as `https://balexandre.github.io/lisbon-guide`

## Notes

- The map, fonts and map library load from the internet (OpenStreetMap, Google Fonts, cdnjs), so the page needs a connection
- `lisbon_places.csv` is optional. To get the places into Google Maps, import it at mymaps.google.com (Import, then choose the file) and use the `Category` column to make layers
